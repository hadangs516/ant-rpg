# 개미 키우기 RPG · v2.0.0

채집하고 동료를 도우며 성장하는 2D 개미 생활 RPG입니다. 7개 챕터에서 우리 굴, 정원, 감옥, 지하, 이끼 군락, 갈대 군락, 왕실, 변경을 탐험합니다. 여왕이 되면 클리어가 기록되며 이후에도 생활·동맹·원정이 계속됩니다.

## 이번 파일 적용 방법

1. 구글 시트의 Apps Script에 **이번 Code.gs 전체 내용**을 붙여 넣고 저장합니다. **배포 → 배포 관리 → 연필 → 새 버전 → 배포**까지 해야 반영됩니다.
2. **전체 ZIP을 풀고 그 안의 파일과 폴더를 모두** GitHub ant-rpg 저장소 맨 위에 올려 덮어씁니다. index.html이 저장소 첫 화면에 보여야 합니다.
3. 배포가 끝난 뒤 게임을 새로고침하고 오른쪽 아래 **v2.0.0**을 확인합니다. 기존 계정으로 로그인해 **설정 → 지금 저장**을 눌러주세요.

기존 시트나 계정을 지울 필요는 없습니다. 자세한 버튼 순서는 [업데이트 안내](apps-script/설치안내.md)에 있습니다. 이전 Apps Script를 그대로 두면 새 이야기 저장이 빠지므로 게임이 업데이트 안내를 표시합니다.

## 조작

| 기능 | PC | 모바일 |
|---|---|---|
| 굴 안팎 이동 | WASD / 방향키 | 왼쪽 아래 조이스틱 |
| 대화·작업·출입 | 가까이에서 E / 오른쪽 아래 버튼 | 가까이에서 오른쪽 아래 버튼 |
| 지도 | M / 지도 버튼 | 지도 버튼 |
| 대사 빠르게 읽기 | 대사를 누르면 한 글자 추가, 길게 누르면 가속 | 동일 |
| 집의 페로몬 | 정원에서 집 버튼, 다시 누르면 끄기 | 동일 |

지도에는 자동 이동 기능이 없습니다. 임무 카드를 펼치면 목표와 필요한 수량을 볼 수 있습니다. 대화에서는 선택지에 따라 반응이 달라지며, 잘못 대답해도 다시 말을 걸 수 있습니다.

## 새로 달라진 생활

- 등급에 따라 방과 이웃 군락이 열립니다. 공헌도는 소모하지 않는 신뢰이며 지역 해금에도 필요합니다.
- 씨앗으로 이동·작업·운반 도구를 강화합니다. 통행증이 없고 씨앗이 부족하면 문지기의 일을 도와 입장할 수 있습니다.
- 금지 구역에 반복 진입하면 일반 감옥에 갑니다. 대기·씨앗·청소 중 원하는 방식으로 나옵니다.
- 즉위 직전 새 이야기가 시작됩니다. 균열, 암호, 외부 군락과의 동맹을 거쳐 왕실에 도전합니다.
- 천적은 경비 개미들과 함께 현장에서 막아야 합니다. 방치하면 굴에 침입해 멸망 엔딩이 나지만 재도전할 수 있습니다.
- 여왕은 대응 지시·집결과 해산·몸동작·꾸미기·공물·변경 원정을 선택할 수 있습니다.
- 굴착조는 160초마다 공사를 돕지만 마지막 흙벽은 플레이어가 직접 엽니다. 개통 뒤에는 새 방을 보강하는 일거리가 이어집니다.

기존 30개 기본 임무에 탈옥·동맹 이야기 23단계를 추가했습니다. 첫 클리어 분량을 늘렸으며, 독서·탐험·선택 활동에 따라 걸리는 시간이 달라집니다. 정해진 시간만큼 기다려야 클리어되는 방식은 아닙니다.

## 계정과 저장

한글 아이디 2~12자와 네 자리 PIN으로 로그인합니다. 0516처럼 0으로 시작하는 PIN도 유지됩니다. 플레이 중 1분마다 자동 저장하며 설정에서 즉시 저장할 수 있습니다. 로그인 횟수·활동 플레이 시간·진행·동맹 등은 운영자 시트에 한글로 기록됩니다. 이미 여왕인 기존 계정은 강등되지 않습니다.

모바일은 기종을 묻지 않고 전체화면을 요청하지 않습니다. 설치해서 실행할 때도 동일합니다. 주소창과 화면 높이 변화에 맞춰 조절합니다.

## 포함 파일

게임 전체, Apps Script, favicon SVG/ICO/16·32·48px, 앱 아이콘 192·512px, 애플 터치 아이콘 180px, 카카오 미리보기 800×400px, 공유 이미지 1200×630px가 들어 있습니다. 공유 주소는 기존 hadangs516.github.io/ant-rpg/에 맞춰져 있습니다.

개발 확인은 Node.js에서 npm test, npm run check를 사용합니다. 직접 실행하려면 node tools/serve.mjs 후 http://127.0.0.1:4173으로 접속합니다. 일반 업로드에는 이 명령이 필요 없습니다.
