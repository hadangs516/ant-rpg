# 개미 키우기 RPG v2 구현 계획

사용자 제작 승인: 2026-09-16. 기준 명세: ../../../차기업데이트-요구사항.md. 목표 v2.0.0.
작업 계획 스킬의 권장 분담 실행을 사용하되 파일별 소유를 나누고 주 작업에서 통합 검증한다.
기술: 기존 정적 ES modules, Canvas 2D, Node tests, Google Apps Script. 빌드/설치 없이 GitHub 업로드.
전역 규칙: 한글 ID+문자열 PIN 유지, 60초 저장, 기존 계정 보존, 모든 저장 단어 한글, 전체화면/게스트 없음.

## 데이터 계약
- 기존 state.version=1 및 기존 30개 quest ID를 유지. 새 state.campaign 객체를 추가한다. 내부 항목도 모두 한글.
- campaign: {'단계':0,'진행':0,'동맹':[],'감옥':'없음','형기':0,'침입':0,'균열':0,'암호순서':0,'강화':{'이동':0,'작업':0,'운반':0},'통행증':[],'개통':false,'수색':[],'왕실체력':100,'원정':0,'모션':'없음','집결':false,'긴급':null}.
- 긴급 값: null 또는 {'종류':'천적'|'비','남은초':180,'진척':0,'지시':false,'실패':false}. 별도 체크포인트는 저장된 실패 상태에서 재도전으로 안전한 입구 복귀 가능하도록 구현.
- world.scene: nest,outside,prison,depths,moss,reed,throne,frontier. campaign의 한국어 항목 그대로 시트의 '새 이야기' 복원 자료에 넣고 scene은 한국어 이름으로 인코딩.
- campaign.단계 0..24 (0 미진입, 1~23 탈옥/동맹/여왕전, 24 즉위). 기존 cleared=true 자료는 단계24로 이전.
- 기존 30번째 royal 임무는 탈옥 이야기를 시작하며, 여왕전 승리 후에만 완료 처리.

## 공개 월드 API (통합용)
기존 constructor/getEntities/nearest/setState/setMode/update/render/getSnapshot/applySnapshot/drawMap/recruit/consume/dig/setEvent 유지.
신규: toggleHomeTrail(), setActivity(entity|null), commandFollowers(boolean), emote(name), onTrespass(room) 콜백.
새 지역 상호작용: type='story', id 한국어(균열,낡은기록,돌개,물길,빛버섯,메아리,초롱,길막힌문,모래,수문장,녹슨문,비밀승강기,은빛전투,원정깃발,상점), type='portal'이며 destination scene 명시.
새 지역/문 진입 허용 판정은 main/controller가 처리. world는 표시와 이동/충돌 담당.
잠긴 방: scout rank1, guard rank2, garden rank3, royal rank4. 낮은 등급 필수 NPC/작업 동선이 차단되지 않게 검사.

## 재개
항상 제작진행.md를 먼저 읽고 완료한 항목은 반복하지 않는다. 재시작 첫 안내에 남은 검증을 포함한 대략 진행률을 말한다. 완성 이전 파일을 배포 준비 완료로 표시하지 않는다.
