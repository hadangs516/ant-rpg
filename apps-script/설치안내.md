# 개미 키우기 RPG · 2.0.0 업데이트 방법

**기존 시트와 계정은 그대로 두고, 아래 두 가지만 교체하면 됩니다.**

## 1. Apps Script 교체

1. 게임 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`의 기존 내용을 모두 지우고, 이번에 받은 `Code.gs` 전체 내용을 붙여 넣은 다음 **저장**합니다.
3. 오른쪽 위 **배포 → 배포 관리**를 누릅니다.
4. 현재 사용 중인 웹 앱을 선택하고 **연필 모양 수정**을 누릅니다.
5. **버전 → 새 버전**을 선택합니다. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**인지 확인합니다.
6. **배포**를 누릅니다.

**저장만 하고 끝내면 게임에 반영되지 않습니다. 반드시 3~6번까지 해주세요.** 기존 배포를 수정하면 주소는 그대로라서 게임 파일에서 주소를 고칠 필요가 없습니다.

이미 시트가 잘 작동했다면 `시트준비`를 다시 실행할 필요는 없습니다. 기존 플레이어 행이나 열을 지우지 마세요. 이전 계정과 진행은 유지됩니다.

## 2. GitHub에 게임 파일 교체

1. 이번에 받은 **게임 전체 ZIP**의 압축을 풉니다.
2. 압축을 푼 곳에서 `index.html`, `styles.css`, `src`, `assets` 등이 보이는 폴더를 엽니다.
3. GitHub의 **ant-rpg 저장소 → Add file → Upload files**로 들어갑니다.
4. **그 폴더 안의 파일과 폴더를 전부** 끌어 넣습니다. 폴더 자체를 한 겹 더 넣지 마세요.
5. 아래 **Commit changes**를 누릅니다.

기존 파일은 같은 이름의 새 파일로 덮어쓰면 됩니다. 별도 설치나 명령어 실행은 필요 없습니다.

GitHub Pages가 이미 켜져 있으면 주소는 그대로 사용합니다. 설정이 필요하면 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 선택하세요.

## 3. 반영 확인

GitHub의 배포가 끝나면 게임 주소를 새로고침하세요. 예전 화면이 계속 나오면 PC에서는 **Ctrl + Shift + R**, 휴대폰에서는 게임 탭을 닫았다가 다시 열어 보세요.

- 오른쪽 아래 버전이 **v2.0.0**인지 확인합니다.
- 기존 계정으로 로그인하고 **설정 → 즉시 저장**을 누릅니다.
- **온라인 저장 완료**가 표시되고 시트의 **게임 버전**이 **2.0.0**으로 바뀌면 연결 완료입니다.
- 비밀번호 첫 자리가 `0`인 계정도 그대로 사용할 수 있습니다.

**“새 Apps Script를 새 버전으로 배포해야 합니다”가 나오면 1번의 배포 관리부터 다시 확인하세요.**

제작 중 저장 검사는 별도 테스트 시트 모형으로 수행했습니다. 실제 구글 시트와의 연결은 위 마지막 단계에서 확인해주세요.
