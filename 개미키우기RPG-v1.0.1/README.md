# 개미 키우기 RPG

**버전 1.0.1** · 작은 일개미로 태어나 동료와 먹이를 나르고, 땅굴을 넓히며 여왕으로 성장하는 2D 생활 게임입니다. 첫 즉위까지 약 30분을 목표로 구성했으며, 탐험과 사건 참여에 따라 플레이 시간은 달라집니다. 여왕이 되면 클리어가 기록되고, 이후에도 산책과 군락 생활을 계속할 수 있습니다.

## 먼저 실행하기

게임 폴더에서 아래 명령을 실행한 뒤 [로컬 게임 열기](http://127.0.0.1:4173)에 접속하세요. Node.js가 필요하며 별도 패키지 설치나 빌드는 없습니다.

```sh
node tools/serve.mjs
```

`index.html`을 두 번 클릭해 여는 대신 위 주소로 실행하세요. 게임은 브라우저의 자바스크립트 모듈을 사용합니다.

온라인 가입과 저장을 사용하려면 먼저 [구글 시트 설치 안내](apps-script/설치안내.md)에 따라 제공된 Apps Script를 설치하고 배포해야 합니다. 구글 시트 서버를 준비하기 전에는 **기기 체험**으로 게임을 확인할 수 있습니다. 기기 체험은 같은 브라우저에만 저장되며 온라인 계정과 별도로 관리됩니다.

## 처음 플레이할 때

1. **군락에 들어가기**를 누르고 PC 또는 모바일을 선택합니다. 모바일은 휴대폰 종류도 선택합니다.
2. 온라인 계정은 한글 아이디 2~12글자와 숫자 네 자리 PIN으로 가입하거나 로그인합니다. `0516`처럼 영으로 시작하는 번호도 그대로 사용할 수 있습니다.
3. 입구의 길잡이 **봄이**에게 말을 걸어 첫 임무를 시작합니다.
4. 임무 카드의 목표를 수행하고 의뢰한 개미에게 돌아가 보상을 받습니다. **길 안내**로 목적지를 찾을 수 있습니다.

가입 안내 문구는 다음과 같습니다.

> 진행 상황을 불러오기 위해 계정과 진행 데이터를 저장합니다

## 조작

| 상황 | PC | 모바일 |
| --- | --- | --- |
| 굴 안 이동 | 가고 싶은 바닥이나 통로 클릭 | 가고 싶은 곳 터치 |
| 굴 밖 이동 | `W A S D` 또는 방향키 | 왼쪽 아래 조이스틱 |
| 대화·채집·작업 | 가까이 가서 `E` 또는 상호작용 버튼 | 가까이 가서 오른쪽 아래 상호작용 버튼 |
| 굴 출입 | 문 가까이에서 상호작용 | 문 가까이에서 상호작용 |
| 지도 | 지도 버튼 또는 `M` | 지도 버튼 |
| 기록장 | 기록장 버튼 또는 `J` | 기록장 버튼 |
| 목적지 확인 | 임무의 길 안내 | 임무의 길 안내 |

이동 중에도 목적지와 상호작용 대상을 확인하세요. NPC는 방의 왼쪽, 작업 표식은 주로 오른쪽에 있습니다. 원하는 대상이 표시되지 않으면 조금 더 가까이 이동하면 됩니다.

밖에서 집을 찾기 어려우면 **집 방향 안내** 또는 지도를 사용하세요. 굴 안의 지도에서는 방과 연결 통로를 한눈에 볼 수 있습니다.

## 군락에서 할 수 있는 일

- 씨앗, 이슬, 잎 조각을 모으고 필요한 친구에게 전달하기.
- 동료를 모집하고 큰 과자와 산딸기를 함께 운반하기.
- 알방 돌보기, 새 통로 파기, 경비와 빗물 막기 연습하기.
- 15명의 주요 NPC를 만나고 발견 기록과 친구 관계 쌓기.
- 소나기, 큰 곤충의 방문, 길 잃은 정찰조, 군락 소풍 등 짧은 사건에 참여하기.
- 여왕으로 즉위한 뒤 공물을 받고 왕실을 꾸미거나 호위와 산책하기.

등급은 **갓 태어난 일개미 → 견습 일개미 → 숙련 일개미 → 작업대장 → 여왕 후보 → 여왕개미** 순서입니다. 주요 임무를 여섯 개씩 완료하면 승급하며, 몸집과 색, 장식도 달라집니다. 공헌도만 반복해서 모아 승급 단계를 건너뛰지는 않습니다.

시간제 사건은 주요 임무 사이에 선택해서 참여할 수 있습니다. 여왕이 된 뒤에는 일을 쉬어도 강등되지 않습니다. 원하는 만큼 평범한 일상을 이어 가세요.

## 저장과 설정

게임은 1분마다 자동 저장하며 **설정 → 즉시 저장**으로 바로 저장할 수 있습니다. 저장 표시에서 기기에 저장했는지, 온라인 저장까지 완료했는지 확인할 수 있습니다. 온라인 연결이 끊기면 기기에 진행을 임시 보관하고 연결이 돌아왔을 때 동기화합니다.

다른 기기에서 같은 계정을 사용하려면 먼저 현재 기기에서 즉시 저장 후 로그아웃하세요. 여러 기기나 탭이 같은 계정을 동시에 사용하면 오래된 진행으로 덮어쓰지 않도록 재로그인을 안내합니다.

운영자는 구글 시트에서 다음 정보를 한글로 확인할 수 있습니다.

| 분류 | 기록 |
| --- | --- |
| 계정 | 사용자 아이디, 네 자리 비밀번호, 가입·로그인·저장 시각, 로그인 횟수 |
| 활동 | 누적 플레이 시간과 초, 채집·굴착·도움·사건 해결 횟수 |
| 성장 | 현재 등급, 공헌도, 진행 중인 임무와 진척, 완료 임무 수, 클리어·즉위 시각 |
| 생활 | 보유 자원, 발견 기록, 친구 관계, 여왕 생활, 현재 위치 |
| 복원 | 게임 버전, 저장 차수, 한글 항목으로 된 진행 복원 자료 |

플레이 시간은 게임 화면이 활성화된 동안 누적하며, 숨겨진 탭이나 메뉴에 머무는 시간은 제외합니다. 가입 때의 첫 접속도 로그인 횟수에 포함합니다. 네 자리 PIN은 시트에 텍스트로 저장하여 앞자리 영을 유지합니다.

설정에서는 PC·모바일 전환, 휴대폰 종류, 배경 음악과 효과음 음량, 즉시 저장, 로그아웃을 사용할 수 있습니다. 현재 버전은 화면 오른쪽 아래에 표시됩니다.

## 휴대폰 화면

- **안드로이드**: 기기 선택 후 전체화면 버튼을 눌러 진입합니다. 브라우저가 전체화면을 허용하지 않으면 일반 화면으로 계속 플레이할 수 있습니다.
- **아이폰**: 보이는 화면 높이에 맞추고 아래쪽 안전 영역을 반영합니다. 주소창 때문에 하단 조작 버튼이 가려지지 않도록 세로 공간을 조정하며, 가로 너비는 유지합니다.
- 가로·세로 방향을 바꾸거나 브라우저 주소창이 움직이면 화면 크기를 다시 계산합니다. 기기 선택을 잘못했다면 설정에서 바꿀 수 있습니다.

## GitHub Pages로 올리기

1. GitHub에 새 저장소를 만듭니다. GitHub 무료 요금제를 사용한다면 공개 저장소를 선택합니다.
2. 이 `ant-rpg` 폴더 **안의 파일과 폴더**를 저장소 최상위에 올립니다. 저장소 첫 화면에 `index.html`, `styles.css`, `src`, `assets`가 바로 보여야 합니다. ZIP 파일 자체를 올리는 방식으로는 게임이 실행되지 않습니다.
3. 저장소의 **Settings → Pages**를 엽니다.
4. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
5. **Branch**에서 파일을 올린 브랜치(보통 `main`)와 **/ (root)**를 선택하고 저장합니다.
6. 배포가 끝나면 같은 화면의 **Visit site**로 게임을 엽니다. 일반적인 주소 형태는 `https://계정이름.github.io/저장소이름/`입니다.
7. 아래 공유 이미지 주소 설정까지 반영한 뒤 카카오톡으로 최종 게임 주소를 공유합니다.

이 게임은 HTML·CSS·자바스크립트로 구성되어 GitHub Pages의 정적 사이트 배포 방식을 사용할 수 있습니다. 배포 메뉴와 브랜치 설정은 [GitHub 공식 배포 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)를, 무료 요금제의 공개 저장소 지원 범위는 [GitHub Pages 소개](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)를 참고하세요.

### 카카오톡 공유 이미지 주소 설정

파비콘과 공유 이미지 파일은 `assets` 폴더에 들어 있습니다.

| 파일 | 용도·크기 |
| --- | --- |
| `favicon.svg` | 크기에 맞춰 선명하게 표시되는 브라우저 아이콘 |
| `favicon.ico` | 브라우저 호환용 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면, 180×180 |
| `icon-192.png` | 앱 아이콘, 192×192 |
| `icon-512.png` | 앱 아이콘, 512×512 |
| `kakao-preview.png` | 카카오톡 공유 미리보기, 800×400 |
| `share-preview.png` | 일반 대형 공유 미리보기, 1200×630 |

배포 주소가 정해지면 게임 폴더에서 아래 명령을 실행하세요. 예시 주소를 **본인의 실제 게임 주소**로 바꾸면 됩니다.

```sh
node tools/set-site-url.mjs "https://my-account.github.io/ant-rpg/"
```

이 명령은 `index.html`의 `og:image`, `twitter:image`, `og:url`을 실제 주소로 바꿉니다. `index.html`을 다시 GitHub에 올리면 적용됩니다. HTTPS로 공개된 주소를 사용하고, 주소에 로그인 정보나 검색 매개변수는 넣지 않습니다. GitHub Pages의 저장소 경로도 자동으로 유지합니다.

직접 수정하려면 두 이미지 주소를 각각 `실제게임주소/assets/kakao-preview.png`, `실제게임주소/assets/share-preview.png`로 지정하고 `og:url`에 게임 주소를 넣으세요. 미리보기 수집기가 읽을 수 있도록 HTML 안에 고정된 태그로 저장해야 합니다.

`kakao-source.svg`, `share-source.svg`는 공유 이미지의 편집 가능한 원본입니다. 게임 표지와 같은 군락 그림을 사용하며, 제목과 안내 문구를 벡터 글자로 구성했습니다.

카카오톡 미리보기는 서버가 HTML에 적힌 주소를 읽으므로 배포된 이미지 주소가 로그인 없이 열려야 합니다. 이미지 변경 후 이전 그림이 계속 보이면 **카카오디벨로퍼스 → 도구 → 초기화 도구 → OG 캐시**에서 주소의 캐시를 지운 뒤 다시 공유하세요. [카카오 공식 미리보기 FAQ](https://developers.kakao.com/docs/ko/message-template/faq)

## 구글 시트 서버 설치

웹 게임 주소와 저장 서버 주소는 서로 다릅니다. 게임은 GitHub Pages에 올리고, 계정과 진행 기록은 Google Apps Script를 통해 게임 전용 시트에 저장합니다.

- [Apps Script 전체 코드](apps-script/Code.gs)
- [시트 준비·웹 앱 배포·연결 확인 안내](apps-script/설치안내.md)
- 게임에서 사용하는 저장 서버 주소: `src/config.js`의 `API_URL`

처음 제공된 웹 앱 주소는 설정 파일에 들어 있습니다. 기존 배포를 새 코드로 업데이트하여 주소를 유지하거나, 새 웹 앱을 만들었다면 `API_URL`을 새 `/exec` 주소로 변경하세요.

## 수정하거나 이어서 제작하기

| 파일 | 담당 기능 |
| --- | --- |
| `src/content.js` | 등급, NPC, 30개 주요 임무, 사건, 자원 이름 |
| `src/progression.js` | 성장, 임무 완료, 클리어, 저장 자료 정리 |
| `src/world.js` | 두 시점의 월드, 굴 경로, 개미 움직임, 지도 |
| `src/main.js` | 화면 연결, 조작, 상호작용, 시간·자동 저장 |
| `src/audio.js` | 배경 음악과 효과음 |
| `src/storage.js` | 온라인 로그인, 저장, 기기 임시 보관 |
| `src/config.js` | 현재 버전과 저장 서버 주소 |
| `styles.css` | PC·모바일 화면과 버튼 배치 |
| `DEVELOPMENT.md` | 확정 요구, 구현 규격, 작업 재개 기록 |

작업을 이어갈 때는 `DEVELOPMENT.md`를 먼저 읽고 현재 파일과 검사 결과를 확인하세요. 업데이트를 배포할 때마다 `src/config.js`의 `VERSION`과 문서의 버전·변경 기록을 함께 수정합니다.

```sh
npm test
npm run check
```

위 명령은 성장·월드·저장 로직과 소스 파일 검사를 실행합니다. 실제 구글 시트 배포의 연결 여부는 설치 안내의 가입·저장·재로그인 절차로 별도 확인합니다.
