# v1.0.1 검증 결과

- Node 자동 검사 53개 통과: 모든 방 조합의 통로 연결, 굴착 지름길, 자원 재생성, 성장·클리어·복원, 한글 시트, PIN 0516/0000, 요청 재시도, 동시 세션, 응답 유실 후 복구.
- Chrome에서 30개 주요 임무의 상호작용과 보상 수령, 모든 승급, 여왕 즉위, 클리어 후 공물 받기 통과.
- 모바일 화면 390×844, 360×740, 844×390에서 화면 폭·높이, 터치 조이스틱, 지도, 저장, 로그아웃 검증. 개인 브라우저 프로필을 사용하지 않은 자동 검사이며 실제 휴대폰에서 실행한 결과는 아닙니다.
- 폰 OS 선택에 따라 안드로이드 전체화면 요청과 아이폰 높이 대응이 나뉘는지 검사. 실제 전체화면 허용 여부는 기기 브라우저에 따라 달라집니다.
- 주요 임무 검사는 이동 위치 및 가상 시계를 조작해 빠르게 진행했습니다. 처음부터 실제 시간으로 30분 플레이한 측정 결과는 아니며, 30분은 첫 플레이 분량의 설계 목표입니다.
- 파비콘 16/32/48, Apple 180, 앱 아이콘 192/512, 카카오 공유 800×400, 일반 공유 1200×630 확인.
- 모의 서버와 실제 브라우저를 연결해 PIN0516 가입, 로그인 대기 잠금,60초 자동 저장,즉시 저장,로그아웃 후 진행 복원을 확인했습니다.
- 실제 Google Apps Script 배포와 GitHub Pages 게시에는 운영자의 계정 및 배포 설정이 필요합니다. 운영 중인 시트에 테스트 계정을 생성하거나 저장하지 않았습니다.
